# Сценарии LifeOS: свободный текст → intent → действие

Каталог всех интентов из `internal/ai/ports.go` и того, что бот делает после `ResolvedIntent`.  
Разбор фразы: **rule-based → (опционально) LLM** → `dispatchIntent` в Telegram.

Поля `ResolvedIntent`: `Type`, `Title`, `Message`, `Target`, `Unit`, `TimeText`, `Hour`, `Minute`, `AmountCents`, `Currency`, `Confidence`.

---

## Задачи

### Создать задачу — `task.create`

- **Примеры:** «добавь задачу купить молоко», «добавь задачу созвон для проекта свадьба», «добавь задачу отчёт для проектов работа и учёба»
- **Поля:** `Title` (обязательно); опционально `Unit`=`project`|`projects`, `Target` (имя проекта/проектов)
- **Действие:** `CreateTask` на сегодня (средняя приоритетность), с привязкой к проектам если указаны

### Список на сегодня — `task.list_today`

- **Примеры:** «задачи на сегодня», «что у меня сегодня по задачам»
- **Поля:** —
- **Действие:** экран задач на сегодня (как кнопка «📅 Задачи»)

### Выполнить — `task.complete`

- **Примеры:** «выполни задачу купить молоко», «готово: отчёт», «готово созвон»
- **Поля:** `Title` (обязательно)
- **Действие:** `CompleteTaskByTitle`

### Отменить — `task.cancel`

- **Примеры:** «отмени задачу купить молоко», «отмени задачу созвон»
- **Поля:** `Title` (обязательно)
- **Действие:** `CancelTaskByTitle`

### Перенести одну на завтра — `task.reschedule_one`

- **Примеры:** «перенеси задачу отчёт на завтра», «перенеси задачу созвон на завтра»
- **Поля:** `Title` (обязательно)
- **Действие:** `RescheduleTaskByTitle` → due = завтра

### Перенести все (triage-режим) — `task.reschedule`

- **Примеры:** «перенеси задачи», «перенеси все задачи»
- **Поля:** —
- **Действие:** массовый перенос задач на завтра (`RescheduleTasks`)

### По тегу — `task.list_by_tag`

- **Примеры:** «задачи с тегом urgent», «задачи по тегу #дом»
- **Поля:** `Title` = имя тега (обязательно)
- **Действие:** `ListTasksByTag`

### Приоритеты — `query.priorities`

- **Примеры:** «что сейчас важно», «что сейчас самое важное»
- **Поля:** —
- **Действие:** `GetPriorities` (эквивалент inline «🔥 Важное»)

## Напоминания

### Создать — `reminder.create`

- **Примеры:** «напомни вечером позвонить маме», «напомни через час выпить воду», «напомни завтра утром про встречу»
- **Поля:** `Message` (текст напоминания, обязательно); `TimeText` (когда: «вечером», «через час», «в 18:30»…)
- **Действие:** `ScheduleReminder` — парсит `TimeText` в `FireAt` по таймзоне пользователя

### Отменить — `reminder.cancel`

- **Примеры:** «отмени напоминание», «отмени напоминание позвонить», «отмени напоминание молоко»
- **Поля:** `Message` (подстрока для поиска; пусто = последнее pending)
- **Действие:** `CancelReminder` по совпадению текста

## План дня

- **Примеры:** «работаю до 18», «работаю до 18:30»

## Финансы

### Доход — `finance.income`

- **Примеры:** «пришёл заказ на 50 тысяч», «получил 15000», «доход 2000», «запиши доход 5000 фриланс»
- **Поля:** `AmountCents` (обязательно), `Title` (описание), `Currency` (обычно RUB)

- **Поля:** `AmountCents` (обязательно), `Title` (категория)
- **Действие:** `RecordExpense`

### Список долгов — `finance.list_debts`

- **Примеры:** «покажи долги», «мои долги»
- **Поля:** —
- **Действие:** `ListDebts`

### Cash flow — `finance.cash_flow`

- **Примеры:** «финансы за месяц»
- **Поля:** —
- **Действие:** `CashFlowSummary`

### Создать долг — `finance.create_debt`

## Проекты

### Создать — `project.create`

- **Примеры:** «добавь проект свадьба», «добавь проект MVP в сфере Карьера», «добавь проект ремонт в сферах Дом и Финансы»
- **Поля:** `Title` (имя); опционально `Unit`=`sphere`|`spheres`, `Target`
- **Действие:** `CreateProject` (+ привязка к сферам). Через меню — FSM с пикером сфер

### Список — `project.list`

- **Примеры:** «мои проекты», «список проектов», «проекты сферы Карьера»
- **Поля:** опционально `Target` = имя сферы
- **Действие:** пикер проектов или `projectsBySphereView`

### Задачи проекта — `project.tasks`

- **Примеры:** «задачи проекта свадьба»
- **Поля:** `Title` (имя проекта, обязательно)
- **Действие:** список задач проекта по имени

### Архивировать — `project.archive`

- **Примеры:** «архивируй проект свадьба», «закрой проект MVP»
- **Поля:** `Title` (обязательно)
- **Действие:** `ArchiveProject`

### Прогресс — `project.progress`

- **Примеры:** «прогресс проекта», «сколько осталось до проекта свадьба», «прогресс проекта MVP»
- **Поля:** опционально `Title` (имя проекта)
- **Действие:** `ProjectProgress` (без имени — общий/первый)

- **Запись:** «шаги 8000», «запиши шаги 12000» → `Title` = число → `RecordSteps`
- **Последние:** «мои шаги», «сколько шагов» → `LatestSteps`

### Сон — `health.record_sleep` / `health.latest_sleep`

- **Запись:** «спал 7 часов», «сон 7.5», «спал 7 ч 30 мин» → `Title` или `Hour`+`Minute` → `RecordSleep`
- **Последний:** «мой сон», «сколько спал» → `LatestSleep`

## Сферы жизни

### Создать — `sphere.create`

- **Примеры:** «добавь сферу Карьера», «запиши сферу Здоровье»
- **Поля:** `Title` (имя); пустой title → FSM `beginAddSphere`
- **Действие:** `CreateSphere` (+ экран настроек)

### Список — `sphere.list`

- **Примеры:** «мои сферы», «сферы», «список сфер»
- **Поля:** —
- **Действие:** экран настроек со сферами (`settingsView`)

### Переименовать — `sphere.update`

- **Примеры:** «переименуй сферу Карьера в Работа»
- **Поля:** `Title` = старое имя, `Target` = новое (оба обязательны)
- **Действие:** `FindSphere` + `UpdateSphere`

### Удалить — `sphere.delete`

- **Примеры:** «удали сферу», «удали сферу Карьера»
- **Поля:** `Title` (подсказка)
- **Действие:** `DeleteSphere` (блок, если есть проекты)

## Неизвестное — `unknown`

- **Когда:** rule-based не сматчил и LLM выключен / не уверен / недоступен
- **Поля:** —
- **Действие:** fallback-подсказка (`FormatFallback`)

## Меню и кнопки (минуя AI)

Клавиатура и callback **не** идут в `IntentResolver` — сразу `runAction` / draft FSM.

### Reply-клавиатура

| Кнопка | Action | Эквивалент / эффект |
|--------|--------|---------------------|
| 🏠 Главная | `home` | сводка + inline-действия |
| 📅 Задачи | `tasks_today` | ≈ `task.list_today` |
| 📁 Проекты | `projects` | ≈ `project.list` |
| 🔄 Привычки | `habits` | ≈ `habit.list` |
| 📆 Календарь | `calendar` | ≈ `calendar.list_today` |
| 📊 Статистика | `analytics` | ≈ `analytics.summary` |
| ⚙️ Настройки | `settings` | сферы + настройки |
| 📱 Mini App | `miniapp` | ссылка/inline WebApp |

### Inline (без AI)

| Кнопка | Action | Эффект |
|--------|--------|--------|
| ➕ Задача | `add_task` | FSM: ввод названия → пикер проектов |
| 🔥 Важное | `priorities` | ≈ `query.priorities` |
| 📦 Завал | `triage` | ≈ `plan.triage` |
| ➕ Проект | `add_project` | FSM: название → пикер сфер |
| 🎯 Прогресс | `project_progress` | ≈ `project.progress` без имени |

Также без AI: `task:done:` / `task:cancel:`, `habit:track:`, `project:view:`, `triage:defer`, draft-пикеры `draft:sphere:*` / `draft:project:*`.

## Как подключить LLM

Подробная конфигурация: **[docs/ops/LLM.md](../ops/LLM.md)** (провайдеры, ключи, модели).

Кратко:

1. Получи бесплатный API-ключ [Groq](https://console.groq.com/) (OpenAI-compatible API).
2. Включи LLM: `LIFEOS_LLM_ENABLED=true`.
3. По умолчанию провайдер — OpenAI-compatible (`LIFEOS_LLM_PROVIDER=openai`), base URL Groq, модель `llama-3.3-70b-versatile`. Задай `LIFEOS_LLM_API_KEY` (или `LIFEOS_OPENAI_API_KEY`).
4. Альтернатива локально: `LIFEOS_LLM_PROVIDER=ollama` + `LIFEOS_OLLAMA_URL` / `LIFEOS_OLLAMA_MODEL`.

Порядок: **rule-based всегда первый**. Если фраза не распознана (`unknown`) и LLM включён — запрос уходит в классификатор (тот же JSON-контракт: `message`, `time_text`, …). Сбой/таймаут LLM → тихий degrade в `unknown` / fallback.

## Ограничения

- **Нет multi-turn чата:** каждая фраза — отдельная классификация; контекст диалога не хранится в LLM.
- **FSM-черновики:** создание задачи / проекта / сферы через меню идёт через состояния сессии и inline-пикеры, а не через LLM.
- **Rule-based побеждает:** если regex сматчил — LLM не вызывается, даже при `LIFEOS_LLM_ENABLED=true`.
- LLM только расширяет покрытие **неизвестных** формулировок до того же `ResolvedIntent` → тех же use case.
