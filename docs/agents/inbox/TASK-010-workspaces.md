# TASK-010 — Shared Workspaces (шерированные сферы)

**Приоритет:** P1 (новая эпикa) · **Статус:** DRAFT (Architect переведёт в OPEN после закрытия P0)
**Врата запуска:** старт **строго после** закрытия P0-багов dogfood (`TASK-008-dogfood-p0`).

## Проблема

Сейчас LifeOS — персональный ассистент: все данные (задачи, финансы, календарь, заметки)
привязаны к одному пользователю. Нужно поддерживать **общие воркспейсы** (например «Бизнес»):
сотрудники, своя экономика, календарь, задачи, заметки — изолированно от личного,
но с контролем смешивания на главной.

## Требования

### 1. Сфера = воркспейс (шаринг)
- `life_spheres` получает флаг шеринга + владельцев/участников (`workspaces`, `workspace_members`, роли owner/editor/viewer).
- Сотрудники — участники воркспейса; у каждого свои задачи внутри воркспейса.

### 2. Отдельные домены в контексте воркспейса
- Задачи, экономика (доходы/расходы/планируемые), календарь, заметки, долги, привычки, аналитика —
  всё имеет `workspace_id` (NULL = личное). Внутри воркспейса видно **все дела всех участников**.

### 3. Главная: подмешивание и экраны
- Сегменты на главной: **«Все / Личное / Воркспейсы»** (+ выбор конкретного ws).
- В «Всех» показываются только **мои** личные + **мои** задачи/события из воркспейсов
  (чужие задачи сотрудников там не видны).
- В экране конкретного ws — всё, включая дела других участников.
- Настройки: какие воркспейсы/домены подмешивать на главную.

### 4. Финансовая синхронизация (cross-context)
- Назначаю в воркспейсе планируемый расход «зарплата → сотруднику X», где X — это я:
  в личном контексте появляется зеркало «планируемый доход — зарплата — сумма».
- Идемпотентность: `origin_txn_id` + уникальный индекс; при удалении/редактировании источника зеркало обновляется/удаляется.

## Декомпозиция (см. BACKLOG Epic WS)
WS-01 миграции → WS-02 API ws/members → WS-03 context-фильтры во всех list-API →
WS-04 главная (сегменты) → WS-06 фин-синхронизация → WS-05 настройки → WS-07 календарь →
WS-08 остальные домены → WS-09 Telegram `/ws` → WS-10 экономика/отчёты ws.

## Зоны агентов
- **Backend:** миграции, domain-контекст (`ctx workspace_id`), инвайты, фин-синхронизация (use-case FinanceSync).
- **Frontend:** сегменты главной, экран воркспейса, настройки шеринга, переключатель контекста.
- **Telegram:** `/ws <name>` смена контекста, создание задач/трат в текущем контексте.

Детальные модели данных и пользовательские истории: [ROADMAP.md § Stage 4](../../roadmap/ROADMAP.md), [BACKLOG.md Epic Workspaces](../../roadmap/BACKLOG.md).
